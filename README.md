# E-Commerce Data Warehouse & Business Intelligence

## 📌 Project Overview

This project focuses on building an E-Commerce Data Warehouse and Business Intelligence solution to transform retail data into meaningful business insights. It combines data management, processing, analytics, and interactive Power BI dashboards to support data-driven decision-making.

The project includes an organized data warehouse architecture, data preparation using Python and SQL, and visual analytics for product recommendations and country-level business insights.

## 🎯 Project Objectives

- Build an organized data warehouse for e-commerce data.
- Structure data using Bronze, Silver, and Gold layers.
- Prepare and analyze retail datasets.
- Explore product recommendation opportunities.
- Analyze sales and business patterns across different countries.
- Develop interactive Power BI dashboards for business intelligence.

## 🛠️ Technologies Used

- **Python:** Data processing and analysis.
- **SQL:** Data querying and transformation.
- **PostgreSQL:** Database management and data warehouse storage.
- **Power BI:** Interactive dashboards and data visualization.
- **CSV:** Dataset storage and data exchange.

## 🏗️ Data Warehouse Architecture

The project organizes data into multiple schemas:

- **Bronze Layer:** Stores raw imported data.
- **Silver Layer:** Supports cleaned and transformed data.
- **Gold Layer:** Organizes data for analytics and reporting.
- **Public Schema:** Contains additional database objects where applicable.

## 📊 Dashboards

### 1. E-Commerce Product Recommendation
Explores e-commerce product data to support product recommendation analysis and customer-focused insights.

### 2. Customer Insights
Provides a dedicated dashboard area for exploring customer-related business information.

### 3. Country Insights
Visualizes country-level information through geographical maps and analytical charts to support comparisons across markets.
